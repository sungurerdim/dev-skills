# i18n — text, formats and layout for every locale

Loaded when the product is localized or public. Structured logging is OBS-01; storage types for time and money are DB-20.

### I18N-01 [HIGH] User-facing text hard-coded
- **Detect:** UI strings, `aria-label`/`alt`/`title`/`placeholder` values, notification and email text, error messages and navigation chrome written as literals instead of resource keys; strings built by concatenation (`"Hello " + name`) so word order cannot change; no locale resource setup at all in a product meant for several languages. Detector of SIM-06.
- **Mech:** T `git grep -nIE '>[[:space:]]*[A-Z][a-z]+([[:space:]]+[a-z]+)+[[:space:]]*<|(aria-label|alt|title|placeholder)="[A-Z][a-z]' -- '*.html' '*.jsx' '*.tsx' '*.vue' '*.svelte' '*.astro'` · `git grep -nIE '(Text|SnackBar|Tooltip)\(["'"'"'][A-Z]|Text\("[A-Z]|setText\("[A-Z]' -- '*.dart' '*.swift' '*.kt' '*.java'`
- **Fix:** every user-visible string from the resource bundle with ICU or platform placeholders for variables; the stack's lint for literals (Android Lint `HardcodedText`, eslint-plugin-i18next `no-literal-string`); a pseudo-locale build (accented, ~40 % longer, bracketed) to find leftovers and truncation.
- **Impact:** each literal ships untranslated, and concatenated sentences cannot be translated correctly at all.
- **Source:** DRY / single source of truth; W3C Internationalization, Best Practices for Authoring HTML; ICU MessageFormat; SIM-06.

### I18N-09 [HIGH] Locale files out of sync
- **Detect:** translations missing keys of the source locale, carrying stale keys, or with placeholders missing or renamed; parity checked only by people.
- **Mech:** T `git ls-files -z '*.arb' '*/locales/*.json' '*/i18n/*.json' '*/l10n/*.json' '*/lang/*.json' | xargs -0 -r grep -c '":'` · `git ls-files -z '*/values*/strings.xml' '*.strings' | xargs -0 -r grep -cE '<string |" = "'`
- **Fix:** a check in the gate that diffs key sets and placeholder names against the source locale and fails on drift (a short stdlib script, or the framework's missing-key report); fall back to the source locale at runtime, never to the key.
- **Impact:** users see raw keys or broken sentences, and a missing placeholder can crash message formatting.
- **Source:** ICU MessageFormat; Flutter, Internationalizing Flutter apps (ARB); Android, Localize your app.

### I18N-02 [HIGH] Dates, numbers and currency formatted by hand
- **Detect:** fixed date patterns (`MM/DD/YYYY`), hand-written thousands or decimal separators, `toFixed` for display, currency symbols concatenated to numbers, units and percentages assembled by string; the locale not passed to the formatter.
- **Mech:** T `git grep -nIE 'toFixed\(|(MM|dd|DD)[/.-](dd|DD|MM)[/.-](yyyy|YYYY|yy)|toLocaleString\(\)|strftime\(' -- ':!*test*' ':!*.md'`
- **Fix:** `Intl.DateTimeFormat`/`NumberFormat` (style `currency`, `unit`, `percent`), Flutter `intl`, `DateFormatter`/`NumberFormatter`, ICU, always with the user's locale; currency from the data, not the locale.
- **Impact:** 03/04 reads as March or April depending on the reader, and amounts appear in the wrong format or currency.
- **Source:** Unicode CLDR; MDN, Intl.

### I18N-06 [HIGH] Time zones and DST mishandled
- **Detect:** naive datetimes (`datetime.now()`, `new Date(string)` without zone); local time stored or sent between systems; day arithmetic as `24*60*60` seconds or `86400`; recurring events stored as UTC instants instead of local time plus zone; the user's zone guessed from the server.
- **Mech:** T `git grep -nIE 'datetime\.(now|utcnow)\(\)|new Date\(["'"'"'][0-9]|86400|24[[:space:]]*\*[[:space:]]*60[[:space:]]*\*[[:space:]]*60' -- ':!*test*' ':!*.md'`
- **Fix:** store and exchange instants in UTC (ISO 8601 with offset); keep the IANA zone with local-time recurring events; calendar arithmetic through the zone-aware library (Temporal, `java.time`, `zoneinfo`); display in the user's zone.
- **Impact:** events shift by an hour twice a year and appear on the wrong day for users in other zones.
- **Source:** IANA Time Zone Database; ISO 8601; TC39 Temporal.

### I18N-03 [HIGH] Plurals built with if/else
- **Detect:** `count == 1 ? "item" : "items"` or string suffixes for plurals; locale files missing the CLDR categories their language needs (Polish and Russian `few`/`many`, Arabic `zero`/`two`); gendered or ordinal text built in code.
- **Mech:** T `git grep -nIE '(count|length|size|n)[[:space:]]*(==|===)[[:space:]]*1[[:space:]]*\?|\?[[:space:]]*["'"'"'][^"'"'"']*s["'"'"'][[:space:]]*:[[:space:]]*["'"'"']' -- ':!*test*' ':!*.md'`
- **Fix:** ICU `plural`/`select` messages or the platform plural resources, with every category of each locale filled.
- **Impact:** most languages read ungrammatically for most counts.
- **Source:** Unicode CLDR, Language Plural Rules; ICU MessageFormat.

### I18N-05 [HIGH] Layout breaks right-to-left
- **Detect:** when a supported or planned locale is right-to-left (ar, he, fa, ur): physical properties (`margin-left`, `padding-right`, `left:`, `text-align: left`) instead of logical ones; no `dir` on the root; `EdgeInsets` and `Alignment` with left/right instead of `EdgeInsetsDirectional` and `AlignmentDirectional`; direction-bearing icons (arrows, progress) not mirrored; bidirectional user text without isolation.
- **Mech:** T `git grep -nIE '(margin|padding|border)-(left|right)|text-align:[[:space:]]*(left|right)|(^|[^-])(left|right):[[:space:]]*[0-9]' -- '*.css' '*.scss' '*.less' '*.vue' '*.svelte'` · `git grep -nIE 'EdgeInsets\.only\([^)]*(left|right):|Alignment\.(centerLeft|centerRight|topLeft|topRight)' -- '*.dart'`
- **Fix:** logical properties and directional widgets; `dir` from the locale; mirror directional icons; `<bdi>` or Unicode isolates around user text.
- **Impact:** RTL users get reversed or overlapping layouts.
- **Source:** MDN, CSS logical properties and values; W3C, Structural markup and right-to-left text in HTML; Material Design, Bidirectionality.

### I18N-15 [MEDIUM] Text sorted, cut or counted by code unit
- **Detect:** user-visible lists sorted with plain `sort()`/byte compare instead of a locale collator; truncation with `substring`/`slice`/byte offsets that splits emoji, combining marks or surrogate pairs; length limits counted in UTF-16 units or bytes where users see characters.
- **Mech:** T `git grep -nIE '\.sort\(\)|\.(substring|substr|slice)\(0,|\.length[[:space:]]*(>|<|>=|<=)[[:space:]]*[0-9]' -- '*.js' '*.ts' '*.jsx' '*.tsx' '*.vue' '*.svelte' ':!*test*'`
- **Fix:** `Intl.Collator`/`localeCompare` (ICU collation elsewhere) for display order; `Intl.Segmenter` or the platform's grapheme API for truncation and counting.
- **Impact:** names sort in the wrong order for most languages, and truncated text shows broken glyphs.
- **Source:** Unicode UAX #10 Collation Algorithm; UAX #29 Text Segmentation; MDN, Intl.Collator and Intl.Segmenter.

### I18N-12 [HIGH] Case mapping ignores the locale
- **Detect:** default-locale `toUpperCase()`/`toLowerCase()` for display text in locales with special casing (Turkish İ/ı, Greek final sigma, Lithuanian); case-insensitive comparisons by lowercasing both sides; type-to-confirm dialogs that reject correctly typed input.
- **Mech:** T `git grep -nIE '\.(toUpperCase|toLowerCase)\(\)|\.(upper|lower)\(\)|strings\.(ToUpper|ToLower)\(' -- ':!*test*' ':!*.md'`
- **Fix:** locale-aware mapping for display (`toLocaleUpperCase(locale)`); Unicode case folding (`casefold`, `localeCompare` with `sensitivity: "base"`) for comparison.
- **Impact:** Turkish users see wrong letters, and matching fails on valid input.
- **Source:** Unicode Standard, Case Mappings (SpecialCasing.txt).

### I18N-08 [MEDIUM] Business logic in message files
- **Detect:** ICU `select` or nested conditions in resource files that encode feature availability, prices, tiers or roles rather than grammar (plural, gender, formality).
- **Mech:** M
- **Fix:** branch in code; keep message variation grammatical.
- **Impact:** rules hidden in translations escape tests and type checks, and translators edit business logic.
- **Source:** Separation of concerns; ICU User Guide, Formatting Messages.

### I18N-13 [MEDIUM] hreflang codes too coarse
applies_when: ui∋web
- **Detect:** `hreflang="zh"` where Simplified and Traditional both exist; `pt` or `es` where regional variants differ; no `x-default`; alternates that do not link back.
- **Mech:** T `git grep -nIE 'hreflang="(zh|pt|es|en|fr|de|ar)"' -- ':!*.md'`
- **Fix:** BCP 47 tags with script or region where they disambiguate (`zh-Hans`, `pt-BR`); reciprocal alternates and `x-default`.
- **Impact:** search engines serve the wrong variant to a whole region.
- **Source:** BCP 47 (RFC 5646); Google Search Central, Localized versions of your pages.
